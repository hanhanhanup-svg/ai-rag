# 管理员与知识维护手册

## 1. 首次建立知识工作空间

首位管理员从本机访问系统，在初始化页创建账号。进入“组织与人员”新增知识管理员和知识使用者，填写部门、角色和初始密码。首次使用者应在“我的账号”更改密码；停用账号后，其会话和应用调用权限由后台即时检查。

进入“知识库”按制度、技术、项目或业务领域建库，指定可见范围、责任人及成员。目录和知识库解决业务分类，权限决定哪些人可以查看。

| 身份 | 可进行的工作 |
| --- | --- |
| 系统管理员 | 组织账号、库权限、全部知识管理、审核、模型、备份和集成配置 |
| 知识管理员 | 向可访问知识库上传资料；管理本人或负责知识库内有写权限的文档；处理授权范围内的反馈 |
| 知识使用者 | 查阅已发布且获授权的资料、搜索问答、收藏、提交反馈 |

库可见范围有企业共享、部门共享和指定成员。涉密文档在库权限之外，进一步要求文档责任人、库责任人或指定成员资格。普通成员资格不会直接赋予编辑权。服务端同时保护文件列表、原件下载、检索、问答和会话历史。

## 2. 接入、校对和发布

1. 打开“文件与接入”，主要区域是已接入文件列表，点击“上传资料”。
2. 选择知识库、文件和适当的保密级别，按需要设置生效/失效日期。
3. 重复内容可以跳过；更新原文件选择新版本；确需独立留存时选择副本。系统保留上传原件和哈希。
4. 上传后自动排队解析。可在列表或“处理任务”查看实际进度，失败会显示原因，不会伪装成功。
5. 打开文档详情，校对页码/工作表/幻灯片文本、OCR 结果、摘要、标签和关键条款。扫描件与复杂 Office 图表需人工确认。
6. 设定复审日期，由有权限的人员执行审核发布。待审核内容不会进入员工问答。
7. 搜索一个业务问题，查看引用页与原件，确认新资料已作为正确依据使用。

PDF 和安全位图支持原件内嵌预览。Office 文件可查看解析文本并下载原件；浏览器不会直接执行上传的 HTML。DOCX 的解析逻辑页与 Word 打印版页码可能不同，应以原件核验。

## 3. 更新版本和时效

修改已发布正文时建立新版本，原发布版本保持可用，直到新版本审核发布并到达生效时间。历史版本留存但不会作为最新问答依据。过期、下架和被替代文档退出检索。

需要重做语义向量时使用“重建语义索引”，不应重新解析并覆盖人工校对。该入口创建后台任务，显示排队、生成、可用或失败状态；失败后可查看原因再重试。

“审核与治理”分别显示待办问题和资料格式说明。逻辑页码、表头约定等阅读说明不再计入待整改问题；OCR 缺失、实际解析风险仍需要核对。解析告警可以填写结论后确认，也可以重新打开；确认仅对当前版本与内容生效，后续变更须重新核验。待审核与已失效资料仍按修订和发布流程处理，不能直接点确认消除问题。

复审日期与失效日期独立。复审提醒不会使仍然有效的知识退出检索；失效日期到达时才停止使用。完成复审要填写核验结论及未来的下次复审日期，保留办理人和时间。来源性质、业务维护责任与适用范围用于明确知识边界，不能把行业示例标成内部正式制度。

CSV、TSV 和 XLSX 保留列名、完整记录及来源记录号/工作表行号。文档内容页合并同一表格的片段；宽表在表格内横向滚动。问答需要全量清单或统计时先检查片段连续性和字段一致性，单次最多提供 200 行、18000 字符的表格证据；超过预算或存在缺行时明确说明无法给出完整统计。

“重新解析原件”会创建待审核新版本，旧原件和人工校对保存在旧版本；新解析内容不会自动融合旧校对。只有新版本审核发布后才替代当前有效版本。若人工编辑表格片段的文字，该片段的旧结构化字段会移除并提示重新核对，全表统计暂不可用，防止问答继续使用已被修改的旧数值。

## 4. 搜索、问答和反馈

搜索支持关键词、中文不同表述和制度编号。结果显示出处与页码，可按知识库缩小范围。问答建议带上业务对象、适用条件、日期和具体问题，例如“超过十万元的采购需要哪些审批？”

答案中的 [编号] 可直接打开对应来源，实际使用的依据优先展示，其他候选依据折叠。引用编号以回答正文为准，不因筛选来源而重新编号。

答案有三种清晰状态：模型归纳、原文摘录、依据不足。只有模型实际返回且通过引用检查，才标为模型回答。核验重要条款时应点击引用回到原文，并留意版本及生效时间。

对不准确、缺少知识或过期的内容提交反馈，知识管理员在“反馈中心”记录办理状态和处理说明。建议形成“发现问题—核实原文—修订资料—重新提问—关闭反馈”的闭环。

会话历史和收藏属于当前账号。原引用失效或权限撤回后，历史回答会隐藏并提示重新提问，以免继续传播已经无权使用或过期的依据。

## 5. 资料目录同步

服务器管理员先在 `CONNECTOR_ROOTS` 配置已存在的受控来源目录。平台管理员在“资料同步”填写白名单下的绝对路径、目标库、同步周期，可手动同步或选择 15 分钟、每小时、每日。

相同文件跳过，变化文件创建新版本。勾选“来源删除时下架”后，来源文件删除会下架相应知识；默认不自动下架。同步导入仍需解析与审核，不会绕过发布流程。移除资料源只停止后续同步，已导入资料保留。

同步卡片显示新增、更新、未变化、下架、失败数量与下次时间。若负责人停用或失去权限，定时任务停止导入并给出原因。

## 6. 建立可重复的质量验收

管理员在“质量评测”新增问题，指定知识库和预期来源文档，可填预期关键文本，也可标记应拒答的无依据问题。建议先准备一批经业务人员确认的题目，覆盖同义表述、具体条款、旧版冲突、跨部门权限和确实无答案的情况。

- “检索评测”验证能否召回目标来源、关键文本以及无依据时是否无结果，不消耗聊天模型用量。
- “问答评测”实际调用已配置模型，验证模型回答、来源、关键文本或应拒答结果，会消耗模型服务用量。

可以设置多条必要关键词和“要求完整表格依据”，单独验证是否遗漏记录。问答评测的来源命中只计算正文实际引用的资料；仅被检索到但没有用于答案的候选资料不算命中。每次运行保留该次规则快照。

查看每题结果、耗时和失败原因，再调整资料与配置重跑。页面的通过率仅代表该批题目和判定规则，不代表整个企业知识库在所有问题上的准确率。自动规则也不替代业务人员对条款适用性的判断。

## 7. 建议运行节奏

每天检查解析失败、反馈和待审核；每周复核即将到期知识与无依据问题，补充知识和评测题；每月核对成员权限、应用令牌到期情况与备份恢复演练。具体频次由企业根据制度更新和资料敏感度确定。

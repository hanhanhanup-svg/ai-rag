# 第三方组件说明

项目通过 `package-lock.json` 固定 Node 依赖版本。实际部署安装时各依赖自带许可证文件；项目没有重新授权这些第三方组件。

公开语义模型使用 [Xenova/bge-small-zh-v1.5](https://huggingface.co/Xenova/bge-small-zh-v1.5)，其来源为 [BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5)。仓库版本、来源、文件摘要及模型卡副本随 `models` 目录保留。上游模型卡标注 MIT；同时附上 [FlagEmbedding 许可证原文](https://raw.githubusercontent.com/FlagOpen/FlagEmbedding/master/LICENSE) 的副本 `LICENSE.FlagEmbedding.txt` 供溯源。

主要运行组件包括 React、Vite、Node.js SQLite、Transformers.js、ONNX Runtime、Tesseract.js、中英文 OCR 语言数据、PDF.js、Saxes 与 jose。Docker 文件还声明系统级 Poppler、中文字体和 CA 证书依赖。

模型下载与 npm 安装需要访问对应公开软件源；知识库运行时的本地 OCR 和本地语义向量不需要向软件源发送企业文档。DeepSeek 等聊天服务属于独立外部服务，密钥、用量及企业使用范围由部署方配置。

本轮增加本地语音转写依赖，固定清单为 `scripts/asr-requirements.lock.txt`。本机隔离环境安装 faster-whisper 1.2.1（已安装包声明 MIT）、CTranslate2、PyAV 与对应推理依赖。语音权重来自 [Systran/faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small)，固定仓库版本与各文件 SHA-256 记录在 `models/faster-whisper-small/xrag-manifest.json`；准备与运行分开，运行时使用本地文件。

视频抽帧调用部署机器的 FFmpeg。本项目未将 FFmpeg 可执行文件纳入源码；换机器需安装并配置 `KNOWLEDGE_FFMPEG_COMMAND`，按实际所用发行包随附许可证管理。高级版式工具为可选适配器，不把未安装的外部组件列为已经交付的解析能力。

# 综合查找接口说明

面向业务网页与内部集成的只读接口。根据用户问题自动判断应走**业务场景**、**文档搜索**、**知识图谱**，并给出进入**智能问答**的路由；**不会**在本接口内直接生成模型回答。

页面入口：知识应用 → **综合查找**（`/application/find`）。

## 1. 调用方式

| 项 | 说明 |
| --- | --- |
| 方法 / 路径 | `GET /api/unified-search` |
| 鉴权 | 登录会话（`credentials: 'include'`），与业务网页相同 |
| 频率 | 每用户约 60 次 / 分钟 |
| 机器可读说明 | `GET /api/unified-search/spec` |

### 查询参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `q` | 是 | 查找语句，最长 1000 字 |
| `baseId` | 否 | 限定单个有权访问的知识库 |

### 示例

```javascript
const origin = location.origin; // 或企业知识库域名
const query = new URLSearchParams({
  q: '设备台账与工单有什么关联？',
  // baseId: '实际知识库ID'
});
const result = await fetch(`${origin}/api/unified-search?${query}`, {
  credentials: 'include'
}).then(async (response) => {
  const body = await response.json();
  if (!response.ok) throw body;
  return body;
});
```

## 2. 响应要点

| 字段 | 含义 |
| --- | --- |
| `intent.channels` | 各通道得分、是否选用及可解释原因 |
| `intent.matchedScenarios` | 命中的业务场景与任务 |
| `strategy` | 主通道与选用策略摘要 |
| `documents.items` | 文档原文命中摘要 |
| `scenarios.items` | 场景任务相关资料 |
| `graph` | 按需返回实体、路径与证据；未选用图谱时为 `null` |
| `routes` | 跳转场景 / 搜索 / 图谱 / 问答的前端路径 |
| `nextActions` | 建议的下一步操作 |

权限与知识有效期规则与 `/api/search`、推荐接口、图谱接口一致：仅返回当前账号可访问、已发布且在有效期内的内容。未命中时返回明确 `emptyReason`，不会伪造结果。

## 3. 与相关接口的关系

| 能力 | 接口 | 说明 |
| --- | --- | --- |
| 综合查找（本接口） | `GET /api/unified-search` | 意图分析 + 多通道摘要 |
| 文档检索 | `GET /api/search` | 单通道原文检索 |
| 场景推荐 | `GET /api/recommendations` | 场景/任务资料推荐 |
| 知识图谱 | `GET /api/graph` | 图谱快照与查询 |
| 智能问答 | `POST /api/chat/runs` | 异步生成带引用的回答 |

需要模型归纳时，请使用 `routes.chat` 进入页面，或直接调用问答 run；不要把综合查找的摘要字段当作已验证答案。

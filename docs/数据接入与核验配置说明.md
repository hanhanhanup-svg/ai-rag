# 数据接入与核验配置说明

更新日期：2026-09-08。适用于本项目 Node.js 24 单节点服务。本文描述已实现接口与实际边界；组件“已登记”不等于通过业务样本验收。保留本机免登录，审计主体为“本地工作空间”，不能据此认定具体人员完成审核。

## 1. 已实现功能与边界

| 内容 | 实际行为 | 核验边界 |
| --- | --- | --- |
| PDF、Office、文本 | 保留原件、版本、页或章节定位；正文与表格形成统一证据块 | Word为逻辑页，XLSX为工作表序号，PPTX为幻灯片序号 |
| CSV/XLSX/DOCX/PPTX表格 | 整行记录、表头、源行；XLSX单元格范围与公式缓存说明；Office合并位置 | 不执行宏、公式或外部连接；合并区域不填推测值 |
| 原生PDF | 真实文字范围坐标；列位置稳定时生成表格候选 | 段落可能定位整页文字范围，并非精确逐句框 |
| 扫描表格 | 内置离线Tesseract词框、行列对齐、候选表格与单元格像素框 | 清晰可对齐表格有真实样本验证；复杂合并、多层表头、缺漏仍须人工核对 |
| 原生Office图表 | 读取DOCX/PPTX/XLSX关联图表的内嵌类别和数值缓存，保留包内位置 | 不重算公式；外部数据、单位不明或无缓存时不制造精确数值 |
| 音视频 | 本地ASR时间片段；视频由FFmpeg抽样画面再离线OCR | 单件25MB、最长60分钟；最多12帧、间隔至少10秒，不代表看过每一帧 |
| 网页/API | 白名单、固定DNS解析结果连接、只读快照、版本和来源收据 | 网页单URL；API按约定结构分页，不是任意系统自动适配 |
| 实体关系 | 从设备编号、车站、工单编号字段提取带源行关系候选 | 复核后使用；不自动合并同名实体 |
| 近似/冲突 | 文本指纹、已有本地向量、数值/否定词/范围比较与原文对照 | 初始阈值尚未业务校准；机器不裁定效力、不自动删除原件 |

GET /api/knowledge/capabilities 返回能力与限制。音视频支持 WAV、MP3、M4A、MP4、MOV、WebM、OGG、FLAC；没有可校验ftyp头的旧MOV须重新导出。

## 2. 证据核验

上传后等待解析，再打开“证据校对”，对照原件、范围、质量提示和表格记录数。OCR、复杂合并与启发式表格带 reviewRequired；关键数字、缺漏行与字段归属确认前不能作确定性全表统计。

已发布资料的证据修改生成新待审版本并复制保留原件。新稿发布前旧正式版本继续可用；源权限明确撤回或删除除外。直接修改表格片段文字会移除与文字冲突的旧结构化值并产生警告，完整结构恢复前停止全表统计。

- GET /api/documents/:id/evidence：document、blocks、canManage、版本与revision。
- PATCH /api/documents/:id/evidence/:blockId：revision、blockRevision、reason；可附 text 或 structuredData，不能同时提交；返回 document、blocks、createdVersion。仅提交原因可记录人工确认。
- structuredData 沿用 headers、rows、rowNumbers、totalRows、tableId。片段校对不允许伪造源行、总量或列数；表头必须非空且不重复。
- transcript/frame_text 可附 locator:{startMs,endMs} 校对时间，须在原媒体总时长内。
- cellBounds.row/column 均从1开始；第1行为表头，第一条数据通常为第2行，前端按 rowNumbers 匹配。
- 图像 bbox=[left,top,right,bottom]，image-top-left 按 pageWidth/pageHeight 缩放；PDF原生 pdf-bottom-left 是另一坐标系，不可混用。
- /api/documents/:id/preview 预览，/file 下载；音视频支持单区间Range，始终检查当前权限。

正文、范围或版本变化后，依赖证据的旧关系和复核结论标记过时，应重新提取或检查。

## 3. 本地ASR

适配脚本为 scripts/asr-local.py。当前隔离依赖为 faster-whisper 1.2.1、av 18.1.0；完整版本锁定在 scripts/asr-requirements.lock.txt。Windows项目根目录准备步骤：

~~~powershell
py -3 -m venv .runtime/asr-env
& .runtime/asr-env/Scripts/python.exe -m pip install -r scripts/asr-requirements.lock.txt
& .runtime/asr-env/Scripts/python.exe scripts/prepare-asr.py
~~~

准备脚本下载模型到 models/faster-whisper-small，并生成文件哈希清单。受限网络可离线部署匹配文件。安装、下载、真实转写分别验收；运行脚本使用本地模型，不因首次转写自动下载。

服务配置示例（替换为实际路径）：

~~~dotenv
KNOWLEDGE_ASR_COMMAND=D:/ai-project/ai-rag/.runtime/asr-env/Scripts/python.exe
KNOWLEDGE_ASR_ARGS=["D:/ai-project/ai-rag/scripts/asr-local.py"]
KNOWLEDGE_ASR_TIMEOUT_MS=600000
KNOWLEDGE_FFMPEG_COMMAND=ffmpeg
~~~

重启服务后生效。程序接收 --input 原件路径；stdout 必须只输出一个JSON：

~~~json
{
  "parser": "faster-whisper-local",
  "model": "small-cpu-int8",
  "durationMs": 12000,
  "coverage": "complete",
  "segments": [{"startMs": 0, "endMs": 3800, "text": "实际识别文字"}]
}
~~~

平台验证时长、时间顺序、边界与文本。未配置、模型缺失、无语音、超时、非法JSON均明确失败。complete表示处理完输入，不表示识别正确；站名、编号、数字和单位须结合原音核验。

视频另存 visualCoverage 与 frameSampling：sampled完成指定抽样，partial部分失败，unavailable画面不可用。frame_text 为抽样画面文字，transcript 为音轨转写；画面时间为近似定位，不推断未抽样时段。临时帧处理完清除。

## 4. 网页与业务API

先由运维登记允许来源，再由管理员创建连接器：

~~~dotenv
KNOWLEDGE_WEB_ALLOWED_HOSTS=www.example.org,docs.example.org
KNOWLEDGE_API_ALLOWED_ENDPOINTS=https://business.example.org/api/knowledge
~~~

以上均为示例。公开网页仅HTTPS，拒绝内网、环回、保留地址和自动重定向。API按完整origin与路径前缀允许企业内网HTTPS。本机HTTP契约测试须额外显式开启 KNOWLEDGE_CONNECTOR_ALLOW_HTTP_LOOPBACK=true。

POST /api/connectors 的API示例：

~~~json
{
  "type": "api",
  "name": "设备台账只读来源",
  "baseId": "实际知识库ID",
  "url": "https://business.example.org/api/knowledge",
  "permissionMapping": {"mode": "target_base", "approved": true},
  "fieldMapping": {
    "id": "id", "text": "text", "title": "title",
    "revision": "revision", "updatedAt": "updatedAt",
    "deleted": "deleted", "allowed": "allowed"
  },
  "maxPages": 5,
  "maxBytes": 2097152,
  "freshnessMinutes": 1440,
  "intervalMinutes": 60
}
~~~

源授权必须明确映射到目标库，未确认直接拒绝。当前支持目标库映射，复杂逐人源ACL须专门适配。字段映射仅单层字段名；可选token独立录入、加密保存，不放URL、示例或日志。

maxPages为1—20，每页最多5MB和1000条records。intervalMinutes为0、15、60、1440，0手动；新鲜度默认1440分钟，可设15—43200分钟。网页type为web，不需要业务字段映射，默认登记参考来源，不因抓取成功自动认定为官方有效制度。

API响应约定：

~~~json
{
  "records": [{
    "id": "asset-001", "title": "设备记录", "text": "授权接入的业务正文",
    "revision": "r12", "updatedAt": "2026-09-08T00:00:00Z",
    "allowed": true, "deleted": false
  }],
  "nextCursor": "下一页游标",
  "complete": false
}
~~~

末页不返回nextCursor并标complete。当前采用完整分页快照重查与逐条收据去重，完成后下一次从首页开始，并非通用CDC。失败批次不前移游标，成功记录可重跑去重；不完整抓取或断连不等于删除。

POST /api/connectors/:id/sync 返回 imported、updated、skipped、withdrawn、failed、partial。HTTP 200不代表全批成功，须查看connector.status与failed/partial。

allowed:false或明确deleted:true立即阻断对应来源族的普通访问并保留历史。超过新鲜度上限也停止普通访问和问答引用，维护者可以治理。权限恢复以新待审版本接入，不自动恢复已撤回旧版本。

## 5. 复杂版式适配器

默认内置原生解析与扫描词框表格候选已经可用。PaddleOCR等高级版式引擎未作为已验收默认组件；复杂跨页、多层合并与图像图表精确还原仍需样本验证。

可替换本地进程：

~~~dotenv
KNOWLEDGE_LAYOUT_ENABLED=true
KNOWLEDGE_LAYOUT_COMMAND=适配器程序绝对路径
KNOWLEDGE_LAYOUT_ARGS=["适配器脚本绝对路径"]
KNOWLEDGE_LAYOUT_TIMEOUT_MS=600000
~~~

同样接收 --input，输出 parser、totalPages、coverage、pages。每页含 page、width、height、blocks；每块含 type、text、bbox，类型paragraph/table/chart；table另含 table:{headers,rows}。宽高与框须为真实解析图像像素坐标。

平台拒绝越界框、重复页、缺页却声明complete和无效表结构。提取表格仍要求人工确认；视觉图表说明不会自动成为精确数值。缺配置或执行失败不会静默成功。

## 6. 实体、候选治理及复验

- POST /api/documents/:id/relations/extract 提取带来源行的候选；POST /api/relations/:id/actions 用revision、confirm/reject和reason复核。
- POST /api/knowledge-checks/runs 提交baseId与可选clientRequestId，202返回运行编号；同请求编号不重复创建检查。
- GET /api/knowledge-issues 返回有权查看的原文、来源性质、范围与时效；不暴露隐藏资料的标题、数量或冲突存在。
- 办理须decisionRevision、动作与resolution。confirmed_conflict只能转为核验中，不能一键关闭；忽略须明确误报、提取错误、范围不同或仅相关依据。
- 数值、否定词或来源性质有关键差异时不能确认等价。stale旧结论需重新检查，不可直接沿用。
- 初始近似阈值用于候选排序，并非事实正确概率；正式效果须用独立标注集校准。

隔离复验命令：

~~~powershell
node --test tests/parser.test.mjs tests/parser-ocr.test.mjs tests/table-structure.test.mjs tests/parser-upgrade.test.mjs tests/knowledge-upgrade.test.mjs
~~~

这些测试包含真实Office/PDF、真实扫描表格OCR、实际本机视频抽帧OCR、来源分页/撤权/幂等、证据新版本与治理失效。ASR与外部LAYOUT协议夹具只验证协议，不替代真实语音或Paddle业务质量验收；实际ASR效果、真实来源与浏览器定位须另附验收记录。

实现入口：server/knowledge-upgrade.mjs；解析：parser、table-parser、ocr-layout、media-parser、layout-parser；证据治理：knowledge-evidence、knowledge-checks；来源：source-connectors。接口继续使用现有认证、Origin、ACL和revision控制。

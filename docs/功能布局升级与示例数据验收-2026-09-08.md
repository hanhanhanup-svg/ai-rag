# 功能布局升级与示例数据验收

日期：2026-09-08。项目：X-RAG 企业知识平台。本轮将页面按知识接入、治理、使用和持续改进的实际工作组织，并通过现有业务接口补充地铁行业示例。

## 1. 已落地的功能布局

| 一级入口 | 核心功能 | 工作目的 |
| --- | --- | --- |
| 工作台 | 统一搜索、治理待办、近期资料、知识库入口、生命周期指引 | 明确当前需要做什么 |
| 知识应用 | 业务场景、搜索、智能问答、任务推荐、收藏、反馈、场景配置 | 按业务任务使用知识 |
| 知识资产 | 业务知识库、知识文档、业务对象、知识图谱 | 统一管理内容、对象、关系与来源 |
| 接入加工 | 加工总览、文件接入、资料源同步、解析与索引任务 | 跟踪原始资料到待审核知识 |
| 质量治理 | 统一治理待办、发布与时效审核、重复冲突核验、改进事项、反馈办理 | 关联问题、处理记录和核验依据 |
| 运营分析 | 知识覆盖、答复结果、最近运行、质量评测、用量与追踪 | 用实际记录确定改进方向 |
| 平台管理 | 模型服务、应用接口与事件、运行备份、操作审计 | 集中维护平台运行配置 |

七个入口按当前访问权限显示。本机模式继续免登录，不创建模拟员工账号。原有功能地址保留；知识目录入口统一进入知识文档。

知识库业务空间包含概览、文档、业务对象、应用、质量和设置页签。文档详情优先展示原文与证据，维护操作单独组织。跨页链接传递知识库、文档版本、实体或对象关键词、业务场景和任务。

## 2. 可执行的治理流程

新增改进事项存储与接口，将原问题、关联原文、处理责任范围、计划日期、办理记录和核验结果放在同一条事项中。

- 待受理事项先进入处理中，才能登记核验结果。
- 修订事项要求更新的有效发布版本，或符合要求的实际评测依据；澄清事项要求核对有效发布资料。
- 已完成事项先重新打开再办理，原记录保留。
- 原文权限、版本和有效性变化后重新判断核验依据是否仍有效。
- 反馈可预填登记事项；事项链接可直接定位，刷新后保持定位。

运营数字由实际文档、运行、调用账本和办理记录生成。缺失用量单独标记，不以零用量代替；不编造历史使用趋势、员工表现或模型评测。

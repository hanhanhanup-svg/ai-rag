# 反馈知识积累（机器学习）

反馈详情中的“机器学习”用于把反馈沉淀为可追溯的知识，供后续相关问答参考。

## 使用流程

1. 打开反馈详情，核对问题、反馈内容及已有结论。
2. 点击“机器学习”。首次使用自动创建专用的“机器学习”知识库；相同反馈重复点击不会重复入库。
3. 已有结论的反馈可进入问答参考；没有结论时，可以补充正确做法后纳入，也可以先留空保存为待补充文档。
4. 可从成功提示进入学习文档，查看原始反馈和结论。

现有文档与以后新增的文档默认关联这套学习知识，无须逐个设置。问答只选取与当前问题相关且有权访问的有效结论。资料范围、表格计算和事实引用仍以当前原文为准，历史反馈中的错误答案不会作为已确认结论使用。

## 后台说明

- 专用库以 `systemKind=feedback_learning` 标识，不会接管普通的同名知识库。
- 原件保存问题、反馈与结论；可用检索片段区分反馈问题与已确认结论。
- 保存反馈来源、源文档版本与内容标识，重复请求幂等；反馈变更需要按最新记录重新纳入。
- 学习文档受源资料权限约束，来源删除、撤回、版本变化或访问权变化时停止提供相关经验。
- 本功能通过反馈知识积累和检索辅助改善后续回答，不修改基础模型权重，也不保证每次回答准确。

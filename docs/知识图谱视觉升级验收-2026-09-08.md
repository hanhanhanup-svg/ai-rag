# 知识图谱视觉升级与验收

日期：2026-09-08。范围：知识图谱页面的结构、视觉和交互升级。

## 已完成

- 六层体系固定为：线路网络、车站空间、设施设备、业务记录、问题事件、知识依据。规程与资料同属知识依据层；未知类型保留其他对象兜底。
- 体系全景按实际类型聚合。当前 83 个对象显示为 7 个有数据的类型卡片，87 条独立关系汇总为 6 组类型连线。卡片与连线数量均来自当前可访问数据。
- 关系探索按业务层次排列真实对象，支持类型下钻、1—3 跳扩展、最相关路径与全部关联切换。关系保持原始方向、独立证据与来源身份。
- 采用深蓝画布、细网格、分层配色、对象类型图标、节点编号、邻域高亮。专注模式可在 1280×720 屏幕完整容纳六层全景或四节点证据链。
- 对象及关系详情按需展开，原文区域保持白底；来源版本、行号、合成示例标记和资料链接继续保留。
- 提供列表、缩放、清晰阅读比例、全图适配、键盘操作和手机纵向层级布局。小网络不显示会遮挡节点的缩略导航。
- 修复受控节点重渲染后测量尺寸丢失的问题，避免悬停、选中或尺寸变化后连线消失、适配视口失败。

## 实际验收

### 桌面浏览器

Chrome，1280×720；另完成 1440×900 与 1280×720 往返尺寸检查。

- 全景 7 个类型卡、6 组聚合关系；专注视图中层级标题和卡片全部位于画布内。
- 实际查询词为 `SYN-EQ-005关联规程`，选择 3 跳：聚焦路径 4 个节点、3 条引用连线；展开全部关联为 21 个节点、20 条关系；列表为 20 条。
- 路径为 `SYN-EQ-005 → SYN-WO-007 → SYN-ISSUE-007 → SYN-PROC-007`；点击“关联问题”显示正确来源行 3。
- 悬停、选择对象、选择关系、关闭详情、放大、缩小、恢复全图、全景与查询往返后，节点和连线保持可见。
- 不存在的查询显示空结果；弹窗 Escape 关闭后保留专注状态，再按 Escape 可退出专注。
- 最终四节点路径无隐藏节点，3 个关系依据按钮可见；1280×720 下工作台底部约 705px，全部节点完整显示。
- 冻结源码并重新加载后的独立浏览器控制台：0 个错误、0 个警告。

### 手机浏览器

- 原文跳转准确高亮设备台账来源行 10；三跳关系点击保留来源行 3。
- 初始、悬停、选择、关闭详情、缩放和恢复均保持 4 个节点、3 条连线，无隐藏节点。
- 所有检查页面宽度均为 390px，无页面横向溢出；最终控制台无错误、无警告。
- 本项为浏览器模拟视口验收，未进行实体手机多指触控测试。

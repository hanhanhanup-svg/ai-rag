# X-RAG 企业知识库

这是可在单台服务器运行的企业知识库，包含文件原件留存、审核发布、有效版本、组织权限、中文混合检索、带出处的模型问答、反馈治理、备份恢复及应用集成。

当前正式入口使用 `src/enterprise/`，所有页面读取真实服务端数据。空部署默认不预置业务数据；账号模式首次使用创建管理员，当前本地配置按使用要求免登录。当前工作目录已通过实际导入流程加入地铁行业资料（官方公开摘编和明确标记的合成示例），并保留原件与版本。旧版原型源码保留供参考，不作为功能验收依据。

## 快速开始

要求 Node.js 24 或更高版本，安装依赖和首次准备模型时需要网络。完整交付包已经包含经过校验的公开中文向量模型。

```powershell
npm ci
if (!(Test-Path .env.local)) { Copy-Item .env.example .env.local }
# 在本机编辑 .env.local，填写模型服务密钥，不要把密钥放进前端代码。
npm run model:verify
npm run check
npm start
```

模型缺失时先执行 `npm run model:prepare`。已有 `.env.local` 时不要覆盖。当前工作目录中的实际模型配置已完成；重新复制项目到其他服务器时需要另行配置密钥。

访问 [本地正式版](http://localhost:8787)。当前本机配置免登录，无需账号密码；只有启用账号模式的新部署才引导创建管理员。开发调试使用 `npm run dev`，访问 [开发页面](http://localhost:5173)。两个命令都需要保持进程运行。

Windows 本地部署可运行 `powershell -ExecutionPolicy Bypass -File scripts/protect-local.ps1`，将实际配置和数据目录权限收紧到当前运行账号及 SYSTEM。用其他服务账号运行时，应由管理员给该账号配置等价目录权限。

## 临时本机免登录

在本地 `.env.local` 设置 `AUTH_MODE=local` 并重启，浏览器通过 localhost 可直接使用工作空间，无需账号或密码。该模式只允许本机监听与直接访问，不创建可登录密码，也不向浏览器发放登录会话。上传、检索、问答、审核和备份仍可使用，文档归属和操作记录保存在固定本地工作空间下。

需要恢复账号登录时，将该配置改回 `AUTH_MODE=password` 并重启；已有正式账号和文档保留。若此前未创建正式管理员，系统会引导初始化管理员，原知识库与资料继续保留。向其他设备或正式企业网络开放时使用账号登录模式。
## 已实现的业务链路

- 接入：上传 PDF、DOCX、XLSX、PPTX、文本、HTML、JSON 和常见扫描图片；支持受控文件夹的增量同步。
- 生产：后台持久任务、分页解析、本地中英文 OCR、知识片段、人工校对、审核发布、保密级别、生效与失效时间。
- 使用：权限范围内搜索、中文全文与本地 BGE 向量融合排序、DeepSeek/OpenAI 兼容接口问答、页码与原文引用、收藏与会话历史。
- 治理：版本替换、下架、复审日期、问题反馈办理、质量评测用例和执行记录。
- 管理：管理员/知识管理员/知识使用者、库与文档权限、审计、模型连接测试、运行状态、原件完整备份与可校验恢复。
- 集成：OIDC 统一登录、限定知识库的只读应用令牌、签名 Webhook 与持久化重试。

本地向量模型为 BGE 中文 small v1.5 的固定版本，512 维，在 CPU 上离线运行；聊天归纳使用配置的模型服务。缺失向量模型时使用全文检索，聊天服务不可用时明确显示原文摘录，依据不足时提示无法可靠作答。

从“知识资产 → 知识图谱”进入 `/assets/graph`。支持线路、车站、设备、工单、故障/问题、规程与资料节点，明确编号跨文档关联、1–3跳探索、候选复核、逐条原文定位；搜索与问答融合图关系、关键词及语义证据，并展示引用完整的关联路径。

当前样例可查询 `SYN-EQ-005 关联的工单、资料问题和核验规程`，沿设备、工单、问题、规程跨三份资料核对。示例关系不代表真实地铁运营事件或正式规程。确认关系被驳回、来源过时或权限变化后，不再用于新问答，历史相关结果同步撤回。

## 运行边界

交付目标是单节点、可部署、可维护的企业试点与部门知识库。SQLite 写入锁会阻止两个服务同时操作同一数据目录。检索在进程内计算，未给出未经压力测试的容量或并发承诺；全公司大规模使用前应以实际语料、人员和目标响应时间压测，并按结果迁移到服务化检索与数据库。

企业 SSO、外部事件接收方、正式 HTTPS 域名和服务器备份位置需要对应环境的配置。容器构建文件已提供，当前机器无 Docker 引擎，容器运行验收需在目标服务器完成。

## 后台数据与文档数据库建设

项目部署需要构建并维护业务数据库、文档数据库及检索索引。当前采用 SQLite 保存业务与文档记录，原件保存在 DATA_DIR/uploads；来源目录仅用于接入。独立数据库、统一文档存储等后续建设要求，以及目录白名单、同步与版本规则，见 [后台数据与文档数据库建设说明](docs/后台数据与文档数据库建设说明.md)。
